# list-django-kit

Wiederverwendbares Baukasten-Kit für dynamische Listen, feste Inhaltstypen (`list`, `news`, `faq`, `form_inbox`) und einen visuellen 3-Spalten-Template-Builder im `django-design-studio`-Design.

## URLs
- `/lists/` – Sammlungen & Listenübersicht
- `/lists/create/` – Neue Sammlung aus Vorlage anlegen
- `/lists/<uuid:pk>/` – Listen-/Detailansicht mit dynamischen Feldern
- `/lists/builder/` – Template-Builder (Staff)
